# Gonçalo Alexandre — Portfolio

Premium dark portfolio built in plain HTML, CSS and JavaScript, ready for GitHub Pages.

## Preview locally

Open `index.html` in a browser, or from the folder run `python3 -m http.server 8000` and visit `http://localhost:8000`.

## Publish

1. Unarchive `goncalo-alexandre02/goncalo-alexandre02.github.io` in GitHub Settings → General → Danger Zone.
2. Upload **the contents of this folder** to the repository root on `main` (not the parent folder).
3. Under Settings → Pages, select Deploy from a branch, `main`, `/ (root)`.
4. Visit `https://goncalo-alexandre02.github.io/`.
5. Verify the LinkedIn preview card after publication.
